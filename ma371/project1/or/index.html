Keeping a Fleet Ready

A training event is two weeks away. Should a notional maintenance officer fund prevention or faster repairs?

The closed fleet starts with 30 ready vehicles, 40 in routine maintenance, and 30 in major repair. Compare two proposals with the same fictional $20,000 budget against a target of at least 70 expected-ready vehicles at the end of week 2.

Open notebook in ColabRead guided inquiry

Teaching case: all data, costs, and proposal effects are synthetic. Expected counts are not guarantees of actual readiness. Upload no real personnel or operational data.

Start here · No coding required

  1. Read sections 1–2 of the guided inquiry. Construct the baseline matrix and make your predictions before calculating.
  2. Open the notebook in Colab. Sign in if prompted. Choose Runtime → Run all to display the controls; leave the code unchanged.
  3. Keep the default inputs for your first run and select Run analysis.
  4. Compare the proposals, complete the held-out baseline check, and test sensitivity. Change the inputs or sliders, then select Run analysis again.
  5. Select Export last run and retain the evidence ZIP and run ID. An export reflects the last completed run, not changes you have not run.
  6. Save your own notebook copy through Colab's File menu. Do not rely on the runtime to preserve your work.

If the notebook does not open or the controls do not appear, notify your instructor. The download below can also be opened in an instructor-prepared Jupyter environment.
